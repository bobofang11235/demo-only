## 執行流程與證據

1. 固定模型、硬體、框架版本、測試輸入、生成參數及矩陣設定，記錄啟動與測試命令。
2. 使用 bring-up 版本建立 baseline；先檢查輸出正確性，再量測效能。
3. 記錄 warm-up 次數、正式量測次數、統計方式與量測範圍；原始樣本與失敗結果均保留。
4. 取得佐助（[#5](https://github.com/bobofang11235/demo-only/issues/5)）的優化 patch／PR、版本與回退方式。
5. 在相同條件下重跑優化版本，記錄所有差異；若測試條件改變，重新建立對應 baseline。
6. 執行正確性、回歸與約定時長的穩定性測試，記錄錯誤、逾時及記憶體問題。
7. 比較結果並連結原始證據，說明是否達到約定門檻；未達標時記錄原因及後續工作。

每次執行需記錄 run ID、時間與時區、模型／框架／程式版本、環境設定、完整命令、輸入、原始輸出與錯誤紀錄位置。
